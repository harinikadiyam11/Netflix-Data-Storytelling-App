# Netflix Data Storytelling App

## Project Description

This project is a Data Storytelling App developed using Streamlit, Pandas, and Plotly. The application analyzes Netflix Movies and TV Shows data and presents important insights through charts and visualizations.

## Dataset Used

Netflix Movies and TV Shows Dataset

Dataset Link:
https://www.kaggle.com/datasets/shivamb/netflix-shows

## Features

- Dataset Introduction
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Interactive Filters
- Data Visualizations
- Insights and Findings
- Final Conclusion

## Data Cleaning

- Removed duplicate records
- Handled missing values
- Filled null values in important columns

## Visualizations

1. Movies vs TV Shows Distribution
2. Top 10 Countries Producing Netflix Content
3. Netflix Content Release Trend
4. Rating Distribution
5. Top 10 Netflix Genres

## Key Insights

- Netflix has more Movies than TV Shows.
- The United States has the highest number of Netflix titles.
- Netflix content increased rapidly in recent years.
- TV-MA and TV-14 are the most common ratings.
- Dramas and International Movies are among the most popular genres.

## Conclusion

Netflix has a large and diverse content library. The analysis shows that movies dominate the platform and content production has increased significantly over time. Netflix can continue focusing on popular genres and international content to attract more viewers.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
